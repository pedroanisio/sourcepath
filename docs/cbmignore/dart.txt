# Default .cbmignore additions for Dart / Flutter projects.
#
# Copy/append these entries into your repo's .cbmignore before running
# `python -m codebase_mapper`. They keep machine-generated outputs and
# build artefacts out of the bundle — those files inflate concept counts
# and embedding storage with low information density.
#
# The classifier already routes deterministic generator suffixes
# (.g.dart, .freezed.dart, .mocks.dart, .gr.dart, .chopper.dart,
# .config.dart, .drift.dart, .pb*.dart) to type_='generated' so the
# chunker / embedder / LLM enricher skip them — but the inventory still
# carries the files. Use these patterns to drop them from the inventory
# entirely.
