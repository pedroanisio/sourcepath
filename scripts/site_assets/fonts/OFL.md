# Bundled fonts — provenance & license

These WOFF2 files are self-hosted so the generated static site renders its
intended typography fully offline (no CDN, no runtime fetch).

| File | Family | Source | License |
|---|---|---|---|
| `fraunces-variable.woff2`, `fraunces-variable-italic.woff2` | Fraunces (variable, wght 100–900) | [Fraunces](https://github.com/undercasetype/Fraunces) | SIL Open Font License 1.1 |
| `ibm-plex-mono-400/500/600.woff2`, `ibm-plex-mono-400-italic.woff2` | IBM Plex Mono | [IBM Plex](https://github.com/IBM/plex) | SIL Open Font License 1.1 |

Both families are licensed under the **SIL Open Font License, Version 1.1**,
which permits bundling and redistribution with the software. Full license text:
<https://openfontlicense.org/>.

The `latin` WOFF2 subsets were obtained via the Fontsource distribution
(<https://fontsource.org/>) on 2026-06-03 and renamed for clarity. They are
byte-for-byte upstream subsets; no glyph modifications were made.
